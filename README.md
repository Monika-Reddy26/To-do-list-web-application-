# Focus Desk

A small productivity web app with a task list and a focus timer.

## Features
- Add, complete, and delete tasks
- Filter tasks by All, Open, and Done
- Tasks are saved in the browser (localStorage)
- Focus timer with 15, 25, and 45 minute presets
- Start, pause, and reset the timer
- Responsive layout that works on mobile

## Built With
- HTML
- CSS
- JavaScript
- React (only for the timer, loaded from a CDN)

## Project Structure
- index.html: page structure
- style.css: styling
- script.js: task list logic
- timer.js: React timer component

## How to Run
1. Download or clone this repository.
2. Keep all files in the same folder.
3. Open index.html in your browser.

An internet connection is needed to load React.
